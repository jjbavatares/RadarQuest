# RadarQuest II

Versión modular de RadarQuest preparada para GitHub Pages.

## Estructura

- `index.html`: página principal.
- `css/styles.css`: estética completa.
- `js/app.js`: funcionamiento del juego.
- `js/data.js`: pruebas, coordenadas, enigmas y respuestas.
- `js/vendor/jsqr.js`: lector de códigos QR.
- `assets/images/`: imágenes originales de las pruebas.

Para publicarla, sube todo el contenido de esta carpeta conservando exactamente su estructura.
